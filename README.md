# P-Club — Photography Club Website

A responsive photography club website designed to showcase photography work, club activities, workshops, and events through a clean and cohesive web interface.

## Live Demo

https://photography-club-portfolio.netlify.app/

## Overview

P-Club is a college photography club website featuring a structured interface for presenting photography collections, workshops, events, and club-related information.

For this version, I redesigned the visual interface of the existing project with a focus on improving its visual consistency, color system, spacing, typography, and overall presentation while retaining the existing website structure and functionality.

## Features

- Photography gallery with categorized content
- Workshops and events sections
- Club membership/application section
- Feedback section
- Responsive navigation and layout
- Interactive frontend components
- Responsive design for different screen sizes

## Design

The redesign uses a warm, neutral color palette to create a visual style that complements photography content while maintaining readability and consistency across the website.

The primary visual changes include:

- Redesigned color palette
- Updated backgrounds, buttons, and UI elements
- Improved visual hierarchy
- Consistent spacing and border-radius system
- Refined typography and component styling
- Improved overall visual consistency across sections

## Technology

- HTML5
- CSS3
- JavaScript
- Netlify
